Data Interpretation

Data Interpretation (DI) is an important topic in SSC CGL. Questions are based on analysing numerical information presented through tables, bar graphs, pie charts and line graphs.

1. Types of Data Interpretation

  • Table DI: Data is presented in rows and columns.
  • Bar Graph: Data is represented using bars.
  • Pie Chart: Data is represented as parts of a circle.
  • Line Graph: Data is represented using points connected by lines.
  • Mixed DI: More than one type of graph or table is used.

2. Important Calculations

DI questions commonly require:

  • Addition and subtraction
  • Multiplication and division
  • Percentages
  • Ratios
  • Averages
  • Percentage increase and decrease

3. Percentage Formula

Percentage = (Part / Total) × 100

Example: If 40 students out of 200 students passed:

Percentage = (40 / 200) × 100

Percentage = 20%

4. Average in DI

Average = Sum of Values / Number of Values

Example: Sales for three months are 100, 150 and 200.

Average = (100 + 150 + 200) / 3

Average = 150

5. Pie Chart

A complete pie chart represents 360°.

The value represented by an angle can be calculated using:

Value = (Angle / 360°) × Total

Example: If a sector has an angle of 90° and the total is 800:

Value = (90 / 360) × 800

Value = 200

6. DI Solving Strategy

  1. Read the title and units carefully.
  2. Understand what each row or column represents.
  3. Check whether values are in hundreds, thousands or lakhs.
  4. Identify exactly what the question asks.
  5. Use the shortest calculation possible.
  6. Check the final answer and unit.

7. Example Table

Year Books Sold
2023 200
2024 300
2025 500

Total books sold from 2023 to 2025:

200 + 300 + 500 = 1000 books

8. SSC CGL Practice Questions

Question 1: A company sold 200, 300 and 500 products in three years. What is the total number of products sold?

  • 800
  • 900
  • 1000
  • 1100

Question 2: Find the average of 100, 150 and 200.

  • 125
  • 150
  • 175
  • 200

Question 3: A pie-chart sector has an angle of 90°. If the total value is 800, what value does the sector represent?

  • 100
  • 150
  • 200
  • 250

Answer Key

  • Question 1 → 1000
  • Question 2 → 150
  • Question 3 → 200
