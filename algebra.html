Algebra

Algebra is an important topic in SSC CGL Quantitative Aptitude. Questions are commonly based on algebraic identities, equations, simplification and basic algebraic expressions.

1. Basic Algebraic Terms

  • Variable: A quantity whose value can change, such as x or y.
  • Constant: A fixed value such as 5, 10 or 20.
  • Coefficient: The numerical value multiplied by a variable.
  • Expression: A combination of numbers, variables and operations.
  • Equation: A mathematical statement containing an equality sign.

Example: In 5x + 7, 5 is the coefficient, x is the variable and 7 is the constant.

2. Important Algebraic Identities

(a + b)² = a² + 2ab + b²

(a − b)² = a² − 2ab + b²

a² − b² = (a + b)(a − b)

(a + b)³ = a³ + 3a²b + 3ab² + b³

(a − b)³ = a³ − 3a²b + 3ab² − b³

a³ + b³ = (a + b)(a² − ab + b²)

a³ − b³ = (a − b)(a² + ab + b²)

3. Linear Equation

A linear equation usually has the variable with power 1.

Example: 2x + 5 = 15

2x = 15 − 5

2x = 10

x = 5

4. Simplification

Like terms can be added or subtracted.

Example: 3x + 5x − 2x = 6x

Constants can also be combined:

7 + 5 − 3 = 9

5. Important Shortcut

If you know the value of x + 1/x, you can find:

x² + 1/x² = (x + 1/x)² − 2

Similarly:

x² − 1/x² = (x + 1/x)(x − 1/x)

6. SSC CGL Practice Questions

Question 1: If 2x + 6 = 16, find x.

  • 4
  • 5
  • 6

Question 2: Simplify: (a + b)² − (a − b)²

  • 2ab
  • 4ab
  • a² + b²
  • a² − b²

Question 3: If x + 1/x = 5, find x² + 1/x².

  • 21
  • 23
  • 25
  • 27

Answer Key

  • Question 1 → 5
  • Question 2 → 4ab
  • Question 3 → 23
