Trigonometry

Trigonometry is an important SSC CGL topic based mainly on angles, right-angled triangles, trigonometric ratios, standard values and identities.

1. Trigonometric Ratios

For a right-angled triangle:

sin θ = Perpendicular / Hypotenuse

cos θ = Base / Hypotenuse

tan θ = Perpendicular / Base

cosec θ = Hypotenuse / Perpendicular

sec θ = Hypotenuse / Base

cot θ = Base / Perpendicular

2. Important Relations

tan θ = sin θ / cos θ

cot θ = cos θ / sin θ

sin θ × cosec θ = 1

cos θ × sec θ = 1

tan θ × cot θ = 1

3. Important Trigonometric Identities

sin²θ + cos²θ = 1

1 + tan²θ = sec²θ

1 + cot²θ = cosec²θ

4. Standard Values

Memorize these values for SSC CGL:

θ 0° 30° 45° 60° 90°
sin θ 0 1/2 1/√2 √3/2 1
cos θ 1 √3/2 1/√2 1/2 0
tan θ 0 1/√3 1 √3 Not defined

5. Complementary Angles

If two angles add up to 90°, they are complementary angles.

sin(90° − θ) = cos θ

cos(90° − θ) = sin θ

tan(90° − θ) = cot θ

cot(90° − θ) = tan θ

6. Important SSC Shortcut

Remember the basic order:

sin θ = P/H    |    cos θ = B/H    |    tan θ = P/B

A common SSC CGL question gives one trigonometric ratio and asks for another. Use:

Pythagoras Theorem: H² = P² + B²

7. SSC CGL Practice Questions

Question 1: Find the value of sin 30°.

  • 0
  • 1/2
  • 1/√2
  • √3/2

Question 2: Find the value of tan 45°.

  • 0
  • 1/√3
  • 1
  • √3

Question 3: If sin θ = 3/5, find cos θ for an acute angle θ.

  • 2/5
  • 3/5
  • 4/5
  • 5/4

Answer Key

  • Question 1 → 1/2
  • Question 2 → 1
  • Question 3 → 4/5
